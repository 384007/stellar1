# MMPose / RTMPose (optional). Install into the same env as backend/requirements.txt after PyTorch.
#
# Faster (recommended): no openmim/mim — prebuilt mmcv wheel only (avoids opencv source builds):
#   cd backend && chmod +x scripts/install_mmpose_fast.sh
#   # macOS: MUST use Python 3.9–3.11 (Apple default 3.12/3.13 has NO mmcv wheel — script prints fix steps).
#   #         Match torch 2.1.2 + torchvision 0.16.2 in that venv, then:
#   PYTHON=.venv/bin/python ./scripts/install_mmpose_fast.sh
#   # First mmpose install can take several minutes (large wheels); script prints timestamps + pip progress.
#   # UV=1 ./scripts/install_mmpose_fast.sh  if you have `uv` — often faster. Already-installed packages are skipped.
#   # Linux + Python 3.12: install torch>=2.4 first (script uses mmcv 2.2.0 wheel); 3.11 + torch 2.1.x is simpler.
#   (default: pip; UV=1 to use `uv pip install`)
# Or download mmcv from OpenMMLab first (curl, no git commit):
#   ./scripts/download_openmmlab_wheels.sh
#
# Slower on Mac (openmim may compile opencv):
#   1) pip install -r requirements.txt
#   2) pip install -r requirements-mmaction2.txt
#   3) mim install "mmcv>=2.0.0,<2.3.0"
#   4) pip install -r requirements-mmpose.txt
#
# RTMPose: no separate pip package — use MMPoseInferencer + RTMPose config/.pth.
# After mmpose, install MMDetection for inferencer APIs:  pip install "mmdet>=3.0,<3.3"
# If ``from mmpose.apis import MMPoseInferencer`` fails with pkg_resources, pin:  pip install "setuptools>=70,<81"
# RTMPose inference wiring: services/providers/pose_rtmpose_provider.py

#      STELLAR_RTMPOSE_CONFIG, STELLAR_RTMPOSE_CHECKPOINT (paths or URLs)
#      STELLAR_RTMPOSE_DEVICE (optional, e.g. cuda:0)
#      STELLAR_RTMPOSE_DET_MODEL=whole_image (default, single golfer full frame) or e.g. human + mmdet
